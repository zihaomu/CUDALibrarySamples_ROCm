## 数学定义

Unsigned 使用图内值为零的像素中心为 site，返回精确欧氏最近距离；同距按最小线性像素位置决定索引。不存在 site 时返回正无穷，坐标输出使用 -32768 sentinel。

Signed 保留小数输入。圆图保持原例 `(input - 0.5) * 2` 预处理和零阈值；Lith 输入保持 float32 精度及原例 float32 的 0.1 阈值。项目算法计算到阈值交点集的欧氏距离：水平/垂直相邻像素跨越阈值时线性插值得到子像素 site，恰等于阈值的像素中心也是 site；输出符号来自输入减阈值。该定义能保留小数导致的边界位移，不能先二值化再套 unsigned EDT。

此处是到离散交点集的距离，不声称是到连续双线性等值曲线或 NPP+ 专有 PBA 反走样结果的精确距离。项目明确采用 `ALGORITHM_VARIANT`，对独立 CPU 的同一定义使用固定数值预算验收；原生输出另报告完整差异。

Signed site 排序为水平边、垂直边、恰零像素，同组按源像素线性位置；同距选最小 site ID。绝对 Voronoi 二元坐标使用所选 site 坐标向下取整的网格 anchor，相对二元坐标为当前像素减 anchor。真正距离仍由子像素坐标计算。它不冒充原生 Voronoi 编号；距离与坐标对应关系必须可独立核验。

没有任何交点且全图同号时返回对应符号无穷。signed 可视化保持加 32700 后截断，并定义饱和到 0..65535；无穷分别映射端点。不继承原始 C++ 对越界浮点转无符号整数的未定义行为。NaN/输入无穷明确拒绝，拒绝时不得改写目标。

## GPU 与 CPU 路线

GPU 中 unsigned 使用整数 site 的精确可分离搜索；signed 使用紧凑的阈值交点集，直接比较每个候选的完整二维平方距离后按 site ID 破同距。首次执行前由分离搜索草稿调整为这一方案，避免中间舍入提前丢弃全局等距候选，数学定义与误差预算不变。输入转换、site 生成、距离与 Voronoi 选择、可视化均在 HIP，CPU 负责文件、标量和调度。首次版本允许较高搜索开销，不声明性能相当。

独立 CPU 使用固定 SciPy cKDTree 的点集最近邻和显式同距处理，与 GPU 的分离搜索实现不同。增加解析直线、常量、孤立 site、对称同距、分数平移和反相输入的结构检查；检查符号、零集合、相邻 Lipschitz、距离与所选 site 一致，以及完整 padding/ROI。
