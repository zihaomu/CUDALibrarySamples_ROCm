## ROCm 支持情况

36 个独立源入口；PASSED 36，PARTIAL 0，FAILED 0，BLOCKED 0，UNSUPPORTED 0，NOT_STARTED 0，IN_PROGRESS 0。

候选库：hipRAND, rocRAND。候选不等于已使用；基础探针成功也不等于整库迁移成功。

36 个 generator/distribution 的原始参数、重复性与解析分布矩均验证；MT19937 初始化需较长时限，跨库序列不要求相同。
